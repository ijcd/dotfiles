# jj-flow P1 (status) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (inline) or
> superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Ship `jj-flow status` and `status --graph` — the unified view of the
private stack + PR projection + workspace health — over a new shared library.

**Architecture:** New `dot_local/bin/jjflow-lib.sh` (sourced) owns config + revsets
+ state classification + workspace listing + live-PR detection (lifted from
jj-mirror). New `dot_local/bin/executable_jj-flow` dispatches `status`. P1 does NOT
re-home the other tools — just enough lib for status. Later phases source the lib
back into jj-mirror et al.

**Tech Stack:** Bash 4+, jj 0.43, `gh` (live/merged PR state, injectable), scratch-repo
test harness mirroring `test/jj-mirror/`.

## Global Constraints

- Files: `dot_local/bin/jjflow-lib.sh` (plain, sourced), `dot_local/bin/executable_jj-flow`.
- `jj-flow` sources the lib via `source "$(dirname "$0")/jjflow-lib.sh"` (works in tests and deployed).
- Config `[jj-flow]`, falling back to `[jj-mirror]`/`[jj-integrate]` keys. Keys: trunk, base, work-prefix, pr-prefix, integration, workspace-dir, remote.
- Live/merged PR state injectable: `JJ_MIRROR_LIVE_PRS` (open) + `JJFLOW_MERGED_PRS` (merged) — no network in tests.
- State glyphs: `○` draft · `◐` mirrored · `●` live · `⚠` stuck · `✓` merged. Preserve mirror-graph `──▶` edges.
- Read-only: status NEVER mutates. No `gh` call when injection vars are set or nothing needs PR state.
- Bash 4+; `set -euo pipefail`; `shasum` not `sha256sum`; no jq/python/node.

### Task 2: state classification (the vocabulary)

**Files:** Modify `jjflow-lib.sh`; Test `test/jj-flow/test_state.sh`.

**Interfaces:**
- Consumes: Task 1 config; jj-mirror's `prime_chain`/`first_parent`/`member_diff_hash`/live detection (lifted into lib).
- Produces: `flow_branch_state WIP` → `draft|mirrored|live|stuck|merged`; `flow_branch_drift WIP` → `even|N-behind|conflict`.

State logic:
- `ijcd/<suffix>` absent → `draft`.
- present, suffix ∈ `JJFLOW_MERGED_PRS` (or `gh pr list --state merged`) → `merged`.
- present, base-divergence (reuse jj-mirror `thread_collisions`/stale) → `stuck`.
- present, dest ∈ live set → `live`; else → `mirrored`.

Drift: `flow_drift = count(base..trunk())` (private stack behind trunk); `conflict` if any wip commit conflicts on trunk.

- [ ] **Step 1: failing test — the state matrix.** Scratch repo builds one branch in each state (draft: no ijcd; mirrored: ijcd + `JJ_MIRROR_LIVE_PRS=""`; live: ijcd + injected live; merged: injected merged; stuck: `mk_divergent_thread`). Assert each `flow_branch_state` result.
- [ ] **Step 2: run, verify FAIL.**
- [ ] **Step 3: implement** `flow_branch_state`, `flow_branch_drift`.
- [ ] **Step 4: run, verify PASS.**
